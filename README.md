# ClearRead

React + TypeScript senior-citizen utility app with a Capacitor Android wrapper.

See [ANDROID_BUILD_GUIDE.md](./ANDROID_BUILD_GUIDE.md) for complete APK build
instructions, backend configuration, and Android device testing notes.

Quick start:

```bash
npm install
npm run dev
```

Android project setup (one time):

```bash
npx cap add android
npm run cap:sync
npx cap open android
```
